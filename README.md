# Инструменты для набросков сайтов (ветка tools)

**Основной генератор с 18.10.2026: `cards.py`** — вертикальные карточки 1080×1350 (4:5) для WhatsApp/Telegram:
```
bash setup.sh
LEADS_DIR=leads OUT_DIR=out TMP_DIR=tmp python3 cards.py            # out/<id>.jpg — первое касание
VARIANT=2 LEADS_DIR=leads OUT_DIR=out TMP_DIR=tmp2 python3 cards.py  # out/<id>-2.jpg — повторное касание
```
- Вариант 1: крупный телефон с первым экраном сайта (фото по нише, название, девиз, рейтинг ≥4,5) + карточка с настоящими ценами из 2ГИС, кнопки мессенджеров бизнеса. Фон — из цвета фона фотографии. У половины бизнесов раскладка зеркальная.
- Вариант 2: экран записи / заказа / вопроса мастеру + уведомление «Новая заявка с сайта» в Telegram.
- `ONLY=id1,id2` — сделать только для этих бизнесов.

Старый `make_concepts.py` (горизонтальные 1600×1000) оставлен как запасной.

Не публикуется на сайте. Используется ежедневным поиском клиентов.

```
bash setup.sh                                   # шрифты Google
LEADS_DIR=leads OUT_DIR=out TMP_DIR=tmp python3 make_concepts.py
```
- `leads/<id>.json` — документы из коллекции leads (name, city, addr, cat, niche, rating, reviews, services…).
- Результат: `out/<id>.jpg`.
- Ниши, палитры, тексты и примерные цены — в `niches.py`. Ниша определяется по полю `niche` и названию.
- 3D-иллюстрации (`assets3d/`) и плоские 2D (`assets2d/`): Microsoft Fluent Emoji, лицензия MIT.
- `VARIANT=2` — второй вариант для повторного касания (другая палитра, раскладка, заголовок, 2D-иконки), файл `out/<id>-2.jpg`.
- Поля лида, которые делают набросок личным: `motto` (девиз бизнеса → заголовок), `services` (реальные цены), `rating`, `reviews`.
- Реалистичные фото (`photos/`: `u*.jpg` — Unsplash, `p*.jpg` — Pixabay, список по нишам в `photos/index.json`): в первом варианте наброска крупное фото в первом экране и галерея «Работы». Сейчас есть для ниш: торты, выпечка, кофейни, цветы, груминг, салоны, маникюр, брови, массаж, фитнес, фото, авто, детские, мебель, ремонт, обувь, тату. Теперь есть почти для всех ниш, включая барбершопы, часы, ключи, телефоны, ателье, тату, клининг. `PHOTOS_V2=1` включает фото и во втором варианте. `NO_PHOTOS=1` выключает фото.
